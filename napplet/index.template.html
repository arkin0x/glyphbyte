glyphbyte hand-drawn glyphs, one byte each

Publish a link or a note

Text with a link becomes a cairn: a public nostr event that carries the link, so the first glyphs of its id lead anyone to it. Text without a link becomes an ordinary nostr note. Either way you get glyphs to draw.

Publishing signs it with a key made for it alone and sends it to wss://wheat.oslim.dev. The page then forgets the key, so nobody can edit or delete what you publish: check it first.
